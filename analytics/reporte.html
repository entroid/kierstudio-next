    Cómo se actualiza

    Este reporte es una foto, no un panel en vivo. Un HTML del repo no puede consultar PostHog ni Search Console por su cuenta.

    Para agregar una medición nueva no hace falta tocar el HTML: se agrega un objeto al array mediciones del bloque JSON del principio y la página se redibuja sola, comparando contra la anterior. El historial queda versionado en git, así que el diff muestra exactamente qué se movió entre reportes.
